RAG Retrieval Architecture

StageMethodPurpose
Pre-filterMetadata extraction (regex) Auto-extract ticker / filing_type / year from question; pass as ChromaDB where= and BM25 mask
Sparse recallBM25Okapi (rank-bm25) Keyword exact-match recall · catches ticker symbols, metric names · top-20
Dense recallChromaDB + all-MiniLM-L6-v2 Semantic similarity recall · catches paraphrases · top-20
FusionReciprocal Rank Fusion (RRF k=60) Merge two ranked lists without normalising incompatible scores · up to 40 candidates
RerankCross-encoder ms-marco-MiniLM-L-6-v2 Full (query, passage) cross-attention relevance scoring · replaces cosine similarity
DedupMMR λ=0.7, Jaccard trigram similarity Greedy diverse selection · prevents 3 adjacent chunks from same paragraph · top-3 returned
